# sms-bomber-pro
اس ام اس بمبر پرو که با اسفاده از دو روش به شماره حمله میکنه بسیار قوی
# 📖 راهنمای استفاده از SMS Bomber Pro

---

## 🚀 نحوه اجرا و استفاده

### ۱. نصب کتابخانه‌های مورد نیاز

```bash
pip install customtkinter requests phonenumbers cryptography matplotlib selenium chromedriver-py
```

یا از طریق فایل `requirements.txt`:

```bash
pip install -r requirements.txt
```

---

### ۲. اجرای برنامه

```bash
python sms_bomber.py
```

---

## 🎯 مراحل استفاده (گام‌به‌گام)

### مرحله ۱: وارد کردن شماره تلفن

- شماره مورد نظر را در فیلد `Target Phone Number` وارد کنید.
- فرمت صحیح: `09123456789` (۱۱ رقم با شروع ۰۹)

---

### مرحله ۲: اعتبارسنجی شماره

- روی دکمه‌ی `Validate` کلیک کنید.
- برنامه شماره را بررسی می‌کند و اپراتور را تشخیص می‌دهد:
  - ✅ سبز: معتبر با اپراتور مشخص
  - ⚠️ نارنجی: معتبر با اپراتور ناشناس
  - ❌ قرمز: نامعتبر

---

### مرحله ۳: انتخاب حالت حمله

از منوی `Attack Mode` یکی از گزینه‌ها را انتخاب کنید:

| گزینه | توضیح |
|-------|-------|
| **Divar API (Fast)** | ارسال از طریق API دیوار (حداکثر ۵ پیام) |
| **Ketabrah Selenium** | ارسال از طریق کتاب‌راه (حداکثر ۳ پیام) |
| **Rubika Selenium** | ارسال از طریق روبیکا (حداکثر ۳ پیام) |
| **Aparat Selenium** | ارسال از طریق آپارات (حداکثر ۳ پیام) |
| **Torob Selenium** | ارسال از طریق ترب (حداکثر ۳ پیام) |
| **Full Attack** | همه‌ی ۵ سرویس همزمان |

---

### مرحله ۴: تنظیم تعداد پیام‌ها

- در فیلد `Count` تعداد پیام‌های مورد نظر را وارد کنید.
- برای حالت‌های تکی: حداقل ۱، حداکثر ۳ (به جز دیوار که حداکثر ۵ است)

---

### مرحله ۵: شروع حمله

- روی دکمه‌ی `Start Attack` کلیک کنید.
- پنجره‌ی تأیید نمایش داده می‌شود.
- `Proceed` را بزنید تا عملیات شروع شود.

---

### مرحله ۶: مشاهده نتایج

- **تب Log:** مشاهده‌ی لاگ‌های لحظه‌ای با رنگ‌بندی
- **داشبورد:** مشاهده‌ی آمار موفقیت/شکست و نمودار
- **نوار پیشرفت:** نمایش نرخ موفقیت به‌صورت گرافیکی

---

### مرحله ۷: توقف عملیات

- در هر زمان می‌توانید روی دکمه‌ی `Stop` کلیک کنید.
- عملیات بلافاصله متوقف می‌شود.

---

## 📂 مدیریت مخاطبین

### ذخیره شماره
- شماره را وارد کنید.
- روی دکمه‌ی `Save` کلیک کنید.
- نام و نام‌خانوادگی را وارد کنید.
- روی `Save Contact` کلیک کنید.

### استفاده از مخاطب
- روی شماره‌ی مورد نظر در تب Contacts **دابل‌کلیک** کنید.
- یا روی دکمه‌ی `Use Selected` کلیک کنید.

### حذف مخاطب
- شماره را در تب Contacts انتخاب کنید.
- روی دکمه‌ی `Delete` کلیک کنید.

---

## 🚫 مدیریت لیست سیاه

### اضافه کردن به لیست سیاه
- شماره را وارد کنید.
- روی دکمه‌ی `Add Current` در تب Blacklist کلیک کنید.

### حذف از لیست سیاه
- شماره را در تب Blacklist انتخاب کنید.
- روی دکمه‌ی `Remove Selected` کلیک کنید.

> **نکته:** شماره‌های موجود در لیست سیاه قابل حمله نیستند.

- به تب `History` بروید.
- تمام حملات انجام‌شده به‌همراه جزئیات (زمان، شماره، حالت، نتیجه) نمایش داده می‌شود.

## ⚠️ نکات مهم

| نکته | توضیح |
|------|-------|
| **اینترنت** | برای ارسال از طریق API و Selenium به اینترنت نیاز دارید. |
| **مرورگر Chrome** | برای Selenium باید Chrome روی سیستم نصب باشد. |
| **فایل‌های JSON** | مخاطبین، لیست سیاه و تاریخچه به‌صورت خودکار ذخیره می‌شوند. |
| **قانونی** | فقط برای اهداف آموزشی استفاده کنید. |

## 🆘 رفع خطاهای رایج

| خطا | راه حل |
|-----|--------|
| `chromedriver not found` | Chrome را به‌روز کنید یا chromedriver را نصب کنید. |
| `ModuleNotFoundError` | کتابخانه‌های مورد نیاز را نصب کنید. |
| `ConnectionError` | اتصال اینترنت را بررسی کنید. |
| `403 Forbidden` | ممکن است WAF سایت شما را مسدود کرده باشد. |
